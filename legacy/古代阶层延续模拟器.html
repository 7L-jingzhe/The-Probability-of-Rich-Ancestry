模型设定： 人群按「是否有富人血统」×「当前阶层」分成 4 组： 有血统·富 / 有血统·穷 / 无血统·富 / 无血统·穷。 每代先按跨阶层婚配抑制系数决定跨阶层婚配数量，再按密度依赖生育产生下一代， 然后施加阶层流动（富→穷滑落、穷→富攀升），最后叠加该代内发生的天灾死亡率。
血统判定（本版修正）： 只要父母中有一方当前是富人，其子女就一定算“有富人祖先”——因为父母本身就是子女的祖先。 因此在双侧模式下： 富×富 → 子女必然有血统；跨阶层 → 子女必然有血统；穷×穷 → 只有双方都无血统标记时才无血统。 在仅父系模式下： 富×富 → 子女必然有父系血统；穷×穷 → 取决于父亲本身有无标记；跨阶层 → 假设一半父亲是富人、一半父亲是穷人，按此加权。
跨阶层婚配抑制系数： 0% 表示完全随机配对，此时跨阶层夫妻对数 = R·P / (R+P)， 对应跨阶层夫妻占比 = 2·r·(1-r)（例如富人占 10% 时为 18%）。 100% 表示完全阶层内婚。数值越大，实际跨阶层比例越低。
子女存活率： 富×富婚配使用富人子女存活率，穷×穷婚配使用穷人子女存活率， 跨阶层婚配的子女按两种存活率的平均值计算。 当富人存活率高于穷人存活率时，即便生育数相同，富人阶层的净增长也会更快， 长期看会推高「当前富人占比」。
关于承载力：当总人口 N → K 时，每对夫妻存活子女数平滑降到约 2（更替水平）， 所以人口会稳定在 K 附近。若低密度下每对夫妻的存活子女数本身低于 2，人口会下降， 此时密度依赖只会让生育进一步降低，不会反向拉升。
简化假设：跨阶层婚配的子女按 50/50 分到富/穷两组。 仅父系模式下额外假设各群体内部性别比 1:1，且跨阶层婚配中富方为父、穷方为母与穷方为父、富方为母各占一半。
关键区别：「祖上有富人」指拥有任意一位（或父系线上任意一位）富人祖先——只要存在跨阶层通婚， 这一比例就单调爬升，最终必然趋近 100%，它不回答阶层是否固化。 真正有信息量的是当前富人占比及其随时间的走势。
